# Iris Flower Classification 🌸

## Project Overview
This project uses Machine Learning to classify Iris flowers into three species based on their physical measurements.

## Dataset
The Iris dataset is provided by Scikit-learn.

- 150 samples
- 4 numerical features
- 3 target classes:
  - Setosa
  - Versicolor
  - Virginica

## Features
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Machine Learning Algorithm
Logistic Regression with StandardScaler.

## Project Workflow
1. Load the dataset
2. Explore the data
3. Split data into training and testing sets
4. Preprocess features
5. Train the classification model
6. Evaluate model performance
7. Predict new flower samples

## Evaluation Metrics
- Accuracy
- Confusion Matrix
- Classification Report
